# Play Console – Store listing

App: **Hookline Radar** (`app.hookline.radar`), 1.0.0.
Play Console paths: **Grow users → Store presence → Main store listing** (text and graphics) and **Store settings** (category, tags, contact details). Translations: *Main store listing → Manage translations → Add your own translations* → Greek (el-GR) and German (de-DE).

Character counts below were measured with a script (Unicode code points, which is how Play Console counts; line breaks count as one character each). Limits: app name 30, short description 80, full description 4000.

Rules followed in all three languages: only features that exist in the code/README; no superlatives ("best", "most accurate", "fastest"); no competitor names; no "official"; the government-information disclaimer and sources come first in the full description (Google's requirements for apps that communicate government information); no fixed price, because Play sets the local price per country.

> **Languages note:** the descriptions say the app is available in English, Greek and German. Remove that line (and don't publish the el/de listings as "the app's language") if the Greek and German in-app translations are not in the release you upload.
